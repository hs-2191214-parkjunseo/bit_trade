# 업비트 자동매매 봇 & 모바일 웹 대시보드 (Upbit Multi-Strategy Bot)

업비트(Upbit) 현물 마켓 기반으로 3가지 매매 전략을 24시간 실시간 시뮬레이션(Paper Trading)하고, 스마트폰/PC 어디서든 웹 브라우저로 실시간 수익률과 체결 내역을 모니터링할 수 있는 자동매매 시스템.

---

## 🎯 탑재된 3가지 매매 전략

| 번호 | 전략명 | 핵심 로직 | 장점 / 특징 |
| :--- | :--- | :--- | :--- |
| **01** | **변동성 돌파 (Volatility Breakout)** | 당일 시가 + (전일 고가-저가) × 0.5 돌파 시 매수, 익일 08:55 전량 청산 | 하락장 리스크 차단, 당일 강력한 상승 추세만 공략 |
| **02** | **이평선 골든크로스 + RSI** | 7선 / 20선 골든크로스 발생 & RSI 35~65 건전 구간 매수, 데드크로스 또는 RSI 75 초과 시 청산 | 뇌동매매 방지, 안정적인 중단기 추세 추종 |
| **03** | **스마트 분할 매수 (DCA / Grid)** | 고점 대비 -2% 눌림 시 1차(30%), -4% 2차(40%), -6% 3차 매수, 평단가 +2.5% 반등 시 익절 | 횡보/조정장 방어력 우수, 안정적 수익 누적 |

---

## 📱 주요 기능

1. **완전 독립 가상 계좌 (Paper Trading Engine)**
   * 업비트 실제 수수료(0.05%) 차감 반영
   * 전략별 초기 자금(기본 100만 원) 독립 운용
   * 실시간 평가금액, 누적 손익률, 최대 낙폭(MDD), 청산 승률 자동 계산
2. **모바일 반응형 실시간 웹 대시보드 (`/public/index.html`)**
   * Tailwind CSS 기반 다크모드 UI
   * 5초 주기 자동 갱신 (비트코인 현재가, 전략별 시그널, 체결 로그)
   * 모바일 화면 최적화
3. **과거 데이터 기반 백테스터 내장**
   * 업비트 실제 과거 캔들 데이터를 즉시 불러와 3가지 전략의 수익률을 1초 만에 대조 비교
4. **추후 실거래 즉시 전환 가능**
   * `UpbitRealExchange` 어댑터가 내장되어 있어, API 키만 설정하면 실제 주문으로 전환 가능

## 🚀 로컬 실행 방법

```bash
# 1. 과거 캔들 기반 백테스팅 실행 (수익률 대조)
npm run backtest

# 2. 24시간 실시간 봇 및 대시보드 서버 기동
npm run dev

# 브라우저 접속: http://localhost:3000
```

## ☁️ 노트북 꺼도 24시간 구동하는 클라우드 배포 가이드

> **주의 (Vercel 배포 시 문제점)**  
> Vercel은 Serverless 환경이므로, 사용자가 웹페이지를 볼 때만 잠깐 켜지고 10초 뒤 프로세스가 종료됩니다.  
> 따라서 **노트북을 끄고도 24시간 내내 백그라운드에서 시세를 감시하며 매매하려면 상시 서버 구동 플랫폼(Render 또는 Railway)**에 배포해야 합니다.

### [추천] Render 무료 배포 방법 (5분 소요)
1. 코드를 본인의 **GitHub 레포지토리**에 푸시 (`git push origin main`)
2. [Render](https://render.com) 가입 및 로그인
3. 대시보드에서 **[New +]** -> **[Web Service]** 클릭
4. 본인의 GitHub 레포지토리 선택
5. 설정값 입력:
   * **Name**: `upbit-bot`
   * **Runtime**: `Node`
   * **Build Command**: `npm install && npm run build`
   * **Start Command**: `npm start`
   * **Plan Type**: `Free`
6. **[Deploy Web Service]** 클릭  
   -> 배포 완료 후 발급되는 `https://upbit-bot-xxxx.onrender.com` 주소로 스마트폰에서 접속하면 노트북을 꺼도 24시간 실시간 감시 및 조회가 가능합니다.
